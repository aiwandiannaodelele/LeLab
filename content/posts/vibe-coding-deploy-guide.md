本文面向使用 Vibe Coding 的新手，不用学复杂运维知识，从零讲懂 AI 网站完整上线流程。

## 1. 网站类型

通常来说，Vibe Coding 出的网站一般分 2 类：

**纯静态站点（推荐新手）**

Next.js 静态构建、原生 HTML/CSS/JS、Vue 静态页

- 不用数据库、函数、接口
- 成本极低，大量平台提供免费托管

例：个人主页（如本站）、作品集、工具 Demo、博客

**带后端服务/动态站点（SSR、接口、数据库）**

需要持续运行服务，涉及服务器、环境变量、数据库。

⚠️ 新手不优先尝试，有额外开销与运维难度。

提醒新手：如果你只是做页面 Demo，优先让 AI 生成可静态导出的项目，避开持续运行后端服务器。

## 2. 部署方法

部署方法分为：

**Git 仓库部署**

适合长期迭代项目，绑定代码仓库后，每次推送代码会自动构建、自动更新网站，省心且高效。

**直接上传**

适合临时演示项目，无需搭建仓库，直接上传打包好的静态文件即可快速上线，简单零门槛。

## 3. 域名

网站没域名就像人没名字——IP 地址记不住又难看不专业。

**免费方案**：Cloudflare Pages / Vercel / Netlify 都会送你一个 `你的项目名.pages.dev` 之类的子域名，临时演示完全够用。

**正经方案**：去 Spaceship、Porkbun、Namesilo 买一个，.com 一年也就 60¥。想省钱可以搞 `1l.lol` 这种冷门顶级域，一年才 7¥。

**绑定也很简单**：买了域名 → DNS 解析到你用的托管平台 → 托管平台设置自定义域名 → 等生效就行

新手注意：DNS 解析生效需要几分钟到几小时，别急着刷新。

## 4. 托管平台怎么选

**Serverless 部署最方便**——不需要买服务器、配证书、开端口、配防火墙、防攻击，这些平台全帮你搞定了。

我推荐 **Cloudflare Pages/Workers**，本站就是部署在这上面的。免费额度：

| 平台 | 免费额度 | 特点 |
|------|---------|------|
| **Cloudflare Pages/Workers** | 无限带宽，**每月 3000 分钟构建** | 国内访问快，自带 CDN，SSL 自动配 |
| **Vercel** | 100GB 带宽 | 跟 Next.js 一家，集成最爽 |
| **Netlify** | 100GB 带宽，300 构建分钟 | 老牌稳定 |

选哪个？你用的框架跟哪个平台关系好就选哪个。Next.js 推荐 Vercel 或 Cloudflare Pages/Workers，纯 HTML 随意。

带后端的动态站？那就 Zeabur、Railway、Fly.io，月费 5-20$ 起步，新手不优先。

## 5. 完整上线一条龙

```
写代码 → git push → 自动构建 → 自动部署 → https://你的域名
```

实际上走一遍就是：

1. 本地 `npm run build` 确保能编译
2. `git add . && git commit -m "xxx" && git push`
3. 托管平台检测到推送 → 自动拉代码 → 执行 build 命令 → 把产物丢到 CDN
4. 等几十秒，刷新页面就看到了

第一次部署麻烦点，后面每次更新就只需要 `git push` 一步。Vibe Coding 出来的东西想更新？一样，改完让 AI 改代码 → push → 完事。

## 6. 总结

Vibe Coding 出来的网站，上线门槛其实很低：

静态站 → 托管平台免费部署 + 买个域名 → 完事
动态站 → 稍微麻烦，但新手可以先用静态站练手

关键是：**不要想着一步到位**。先上线，再优化。网站是改出来的，不是设计出来的。
